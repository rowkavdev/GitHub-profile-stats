# Fonts for PNG export

NotoSans-Regular.ttf and NotoSans-Bold.ttf (Noto Sans, Google / the Noto Project,
https://github.com/notofonts/latin-greek-cyrillic) are licensed under the SIL
Open Font License 1.1 (https://openfontlicense.org). They are bundled because
the hosted runtime has no system fonts, so the PNG rasteriser needs its own.
